# Промпт для создания Gothic / Dark Wave сайта с игрой

Этот файл содержит детальный промпт (запрос), с помощью которого можно сгенерировать проект, аналогичный моему. 

## Основной Промпт:

> **Роль:** Ты — Senior Frontend-разработчик и эксперт по UI/UX дизайну.
> 
> **Задача:** Напиши код для одностраничного веб-сайта (SPA), объединяющего в себе визитку и интерактивную игру. Используй чистый HTML, CSS и Vanilla JavaScript. Код должен быть строго разделен на три файла: `index.html`, `style.css` и `script.js`.
> 
> **Общий стиль (Дизайн):**
> *   Направление: Gothic, Dark Wave, строгий минимализм.
> *   Фон: глубокий черный (`#050505`) с легким радиальным градиентом (виньеткой) по краям.
> *   Акцентные цвета: цвет запекшейся крови (`#8b0000`) и холодный серебристый (`#e0e0e0`, `#a3a3a3`).
> *   Шрифты: 'Cinzel' (для заголовков, готический стиль) и 'Montserrat' (для основного текста, минимализм).
> *   Никакого неона. Только строгие рамки, глубокие тени и плавные, медленные анимации (`transition: all 0.5s ease`).
> 
> **Структура (Два экрана):**
> 
> **Экран 1: Игра "Угадай число"**
> 1.  **Заголовок:** "My first AI project" шрифтом Cinzel с эффектом плавного увеличения и кроваво-красного свечения при наведении.
> 2.  **Панель управления:** Три элемента в ряд: кнопка "Сложность", по центру таймер, кнопка "Рекорды".
> 3.  **Выбор сложности:** 3 режима (Легко 1-100, Средне 1-1000, Сложно 1-100000). У каждого режима свой лимит попыток (10, 20, 30). При клике панель выезжает сбоку.
> 4.  **Игровое поле:** Текст "Загадано число от 1 до X", счетчик оставшихся попыток, поле ввода числа с кастомными стрелками (вверх/вниз) внутри, кнопка "Проверить".
> 5.  **Логика игры:** 
>     *   Игра подсказывает "БОЛЬШЕ >>" или "МЕНЬШЕ <<".
>     *   Таймер запускается только после первой попытки.
>     *   При победе: остановка таймера, поздравление (с правильным склонением слова "попытка"), сохранение рекорда в `localStorage`, появление кнопки "Перезапустить".
>     *   При проигрыше (Game Over): красный трясущийся текст с загаданным числом, блокировка ввода.
> 6.  **Рекорды:** Сохранение ТОП-10 результатов в `localStorage` отдельно для каждой сложности. Панель рекордов выезжает сбоку.
> 
> **Экран 2: Визитка, Логотип и Музыка**
> 1.  **Переключение:** Кнопка "Нажми меня" переключает на этот экран (без перезагрузки страницы).
> 2.  **Картинка:** Изображение Самурая. К нему нужно применить CSS-фильтр `filter: brightness(0.6) contrast(1.2)` для мрачности и `mask-image: radial-gradient(...)`, чтобы края картинки плавно растворялись в черном фоне (эффект "вырывания из тьмы").
> 3.  **Текст:** "I’m here and I came to say…" + "your evil SAMURAI". При наведении текст плавно светится красным.
> 4.  **Музыкальный плеер:** В левом верхнем углу свернутая иконка в виде виниловой пластинки (черно-красная). При клике разворачивается мини-плеер: кнопки Play/Pause, ползунок громкости, название трека мелким шрифтом (Cinzel).
> 
> **Спецэффекты (JS + CSS):**
> *   **Атмосферная пыль:** При загрузке страницы JavaScript генерирует 50 маленьких точек (частиц) кроваво-красного цвета по всему экрану. Они медленно парят и мерцают (анимация `@keyframes twinkle`).
> 
> **Адаптивность:** Весь интерфейс должен идеально сжиматься для мобильных телефонов (медиа-запросы `@media`). На телефонах боковые панели должны падать вниз под игровое поле.
