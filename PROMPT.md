# Промпт для создания Киберпанк-сайта с игрой

Этот файл содержит детальный промпт (запрос), с помощью которого можно сгенерировать проект, аналогичный моему. 

## Основной Промпт:

> **Роль:** Ты — Senior Frontend-разработчик и эксперт по UI/UX дизайну.
> 
> **Задача:** Напиши код для одностраничного веб-сайта (Single Page Application), объединяющего в себе визитку и интерактивную игру. Используй только чистый HTML, CSS и Vanilla JavaScript (без фреймворков вроде React). Весь код должен находиться в одном файле `index.html`.
> 
> **Общий стиль (Дизайн):**
> *   Строгий киберпанк, хакерская эстетика.
> *   Фон: абсолютно черный (`#000000`).
> *   Шрифты: 'Rajdhani' для основного текста, 'Share Tech Mono' для кода и цифр.
> *   Неоновые цвета: розовый (`#ff00ff`), голубой (`#00ffff`), синий (`#3333ff`).
> *   Использование CSS-градиентов, свечения (`text-shadow`, `box-shadow`), плавных анимаций (fadeIn, пульсация).
> 
> **Структура (Два экрана):**
> 
> **Экран 1: Игра "Угадай число"**
> 1.  **Заголовок:** Градиентный неоновый текст "SYSTEM: GUESS THE NUMBER" с эффектом мерцания.
> 2.  **Панель управления:** Три элемента в ряд: кнопка "Сложность", по центру таймер, кнопка "Рекорды".
> 3.  **Выбор сложности:** 3 режима (Легко 1-100, Средне 1-1000, Сложно 1-100000). У каждого режима свой лимит попыток (10, 20, 30 соответственно). При клике панель выезжает сбоку.
> 4.  **Игровое поле:** Текст "Загадано число от 1 до X", счетчик оставшихся попыток, поле ввода числа с кастомными неоновыми стрелками (вверх/вниз) внутри, кнопка "Проверить".
> 5.  **Логика игры:** 
>     *   Игра подсказывает "БОЛЬШЕ >>" или "МЕНЬШЕ <<" с неоновыми стрелками терминала.
>     *   Таймер запускается только после первой попытки.
>     *   При победе: остановка таймера, поздравление (с правильным склонением слова "попытка"), сохранение рекорда, появление кнопки "Перезапустить".
>     *   При проигрыше (Game Over): красный трясущийся текст с загаданным числом, блокировка ввода.
> 6.  **Рекорды:** Сохранение ТОП-10 результатов в `localStorage` отдельно для каждой сложности. Панель рекордов выезжает сбоку.
> 
> **Экран 2: Визитка и Музыка**
> 1.  **Переключение:** Кнопка "Нажми меня" переключает на этот экран (без перезагрузки страницы).
> 2.  **Контент:** Картинка (можно использовать заглушку), неоновый градиентный текст "I'm here and I came to say... your evil SAMURAI".
> 3.  **Музыкальный плеер (Пасхалка):** В левом верхнем углу свернутая иконка в виде неоновой виниловой пластинки. При клике разворачивается мини-плеер: кнопки Play/Pause, ползунок громкости, ползунок регулировки громкости, указание авторства трека (текст мелким шрифтом).
> 4.  **Пасхалка (Звездное небо):** При клике на главную картинку фона, на заднем плане генерируются 40 пульсирующих белых точек (звезд) в случайных местах экрана.
> 
> **Адаптивность:** Весь интерфейс должен идеально сжиматься для мобильных телефонов (медиа-запросы `@media`). На телефонах боковые панели должны падать вниз под игровое поле.
