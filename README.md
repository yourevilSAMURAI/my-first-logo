# Моя первая ИИ-визитка

Это мой первый проект, созданный с помощью искусственного интеллекта. Здесь я учусь веб-разработке, осваиваю промпт-инжиниринг и создание интерактивных интерфейсов.

## Посмотреть вживую:
Вы можете поиграть в игру, посмотреть сайт и как он работает, по ссылке:
**[Открыть сайт](https://yourevilsamurai.github.io/my-first-logo/)**

## Что умеет сайт:
*   **Неоновый дизайн** в стиле киберпанк с анимациями и градиентами.
*   **Адаптивная верстка**: сайт идеально выглядит как на ноутбуке, так и на экране смартфона.
*   **Игра "Угадай число"**: интерактивная игра на JavaScript с подсказками "больше/меньше".
*   **Уровни сложности**: 3 режима на выбор (Легко 1-100, Средне 1-1000, Сложно 1-100000).
*   **Счетчик попыток**: игра считает, за сколько ходов вы угадали число.
*   **Система Game Over**: если попытки заканчиваются, игра блокируется, а экран показывает загаданное число.
*   **Умный таймер**: отсчет времени начинается только после первой попытки.
*   **Система рекордов**: локальный ТОП-10 для каждого уровня сложности, который сохраняется в браузере (используется `localStorage`).
*   **Кастомные элементы**: неоновые стрелочки для ввода чисел и умное склонение слова "попытка".
*   **Музыкальный плеер**: стилизованный под виниловую пластинку плеер с возможностью паузы и регулировки громкости.

## Технологии
* HTML5 (семантическая верстка)
* CSS3 (Flexbox, анимации, градиенты, свечение, адаптивность)
* **JavaScript** (логика игры, интерактивность, таймер, работа с `localStorage`, управление DOM и Audio API)
* Нейросети (для генерации кода и идей)
